# ТЗ: Скачать DOCX из `ut-test-reports` (1:1 как `УЗК-бланк заключения.pdf`)

Прочитай файл: `@.claude/basicDocumentationForTheApp/УЗК-бланк заключения.pdf` или `@.claude/basicDocumentationForTheApp/УЗК-бланк заключения.docx`.  
Это **бланк заключения по УЗК**. Содержимое этих файлов одинаковое, только в разных форматах .docx и .pdf. Прочитай тот файл, с которым тебе удобнее работать

## Контекст

- Есть компонент/страница **`ut-test-reports`** с реактивной формой заключения УЗК (РУЗК). Верстка и имена контролов уже сделаны.
- Эталон/шаблон документа — файл **`УЗК-бланк заключения.pdf`** (**`УЗК-бланк заключения.docx`**) - Приложение Г.3, СТО Газпром 15-1.3-004-2023. В нём **жёлтым выделены поля для подстановки значений**.
- На странице есть кнопка PrimeNG: **"Скачать DOCX"** (сейчас без обработчика клика).

## Задача (строго)

Сделай так, чтобы при нажатии на кнопку **"Скачать DOCX"** скачивался документ **"Уведомление"** в формате **.docx** (Word).

Документ должен собираться **на клиенте** с помощью библиотеки **DOCX** (npm пакет `docx`) и быть визуально/структурно **1 в 1** как в **`УЗК-бланк заключения.pdf`** (**`УЗК-бланк заключения.docx`**):

- те же заголовки, подписи, рамки, таблицы, выравнивания, переносы строк;
- те же секции/блоки (верхние два блока, заголовок “ЗАКЛЮЧЕНИЕ №…”, таблица “РЕЗУЛЬТАТЫ КОНТРОЛЯ”, подписи, нижние реквизиты);
- максимальная точность по ширинам колонок/строк и границам таблиц (используй `Table`/`TableCell` с заданными ширинами).

## Данные для подстановки (жёлтые поля)

Все жёлтые поля в PDF заполнять **значениями из заполненной формы `ut-test-reports`**:

- `conclusionNumber`, `conclusionDate`
- `labName`, `attestationNumber`, `normativeDocument`, `otkNumber`
- `defectoscope`, `transducers`, `calibrationBlock`
- `vikConclusionNumber`, `vikConclusionDate`
- `objectName`, `qualityLevel`, `controlVolume`, `routeName`, `pipelineSection`
- `contractor`, `customer`, `welderCode`
- Таблица дефектов: `defects[]` (все колонки как в бланке)
- Итог: `firstWeldNumber` + `finalConclusion`
- Подписи: `inspector.fullName`, `inspector.qualification`, `inspector.date`, и аналогично `approver.*`

Если поле пустое — оставляй **прочерк** как в бланке (не “null”, не “undefined”).

## Требования по реализации

### 1) Зависимости

Установить:
- `docx`
- `file-saver` (или аналог) для скачивания blob в браузере

### 2) Сервис генерации DOCX

Реализовать генерацию docx через отдельный сервис, например:

- `src/app/pages/ndt-dashboard/ndt-test-reports/ut-test-reports/ut-test-reports-docx.service.ts`

В сервисе сделать публичный метод:

- `buildDocx(formValue: /* тип */): Promise<Blob>`

### 3) Логика в компоненте `UtTestReports`

Добавить метод `onDownloadDocx()`:

- если форма **невалидна** → `markAllAsTouched()` и **не скачивать**
- получить `Blob` из сервиса → скачать как файл `Уведомление.docx`

### 4) Привязка к кнопке

Подключить обработчик к кнопке PrimeNG:

- `(onClick)="onDownloadDocx()"`

## Критично: верстка DOCX (1 в 1)

- Формат страницы: **A4, альбом**, поля подобрать под бланк (используй `sections` + `page.size` + `page.margin`).
- Блок “ЗАКЛЮЧЕНИЕ № ___ от «__» ______ 20__ года”:
    - дата выводится так: `«dd» <месяц_прописью> yyyy года`  
      (месяц по-русски в родительном: января/февраля/…)
- Большую таблицу “РЕЗУЛЬТАТЫ КОНТРОЛЯ” собрать через `Table`:
    - заголовок таблицы с переносами слов как в бланке (где нужно — `TextRun` + `break()`),
    - границы (gridlines) включить,
    - ширины колонок выставить вручную (ориентируйся на бланк),
    - строки данных = по количеству `defects`.
- Блоки “Контроль провел … / Заключение выдал …” оформить **табличной сеткой**, чтобы совпали подписи и поля.
- Блоки реквизитов (лаборатория/средства/объект/организации) сверстать двумя таблицами (как на бланке "УЗК-бланк заключения.docx").

## Готовый результат

- Нажал “Скачать DOCX” → скачался `Уведомление.docx`
- Открыл в Word → визуально совпадает с `УЗК-бланк заключения.pdf`
- Все жёлтые поля заполнены значениями из формы
- Таблица дефектов заполняется динамически

## Подсказки (обязательно применить)

- Для уменьшения веса бандла допускается `await import('docx')` внутри метода скачивания.
- Сделай утилиты:
    - `formatRuDate(date: Date): string` → `«04» января 2026 года`
    - `v(value, fallback='__________')` → безопасная подстановка
    - `num(value, fallback='___')` → безопасная подстановка чисел
- **Не используй html-to-docx конвертеры**: только ручная сборка `docx`, иначе не добиться 1:1.
